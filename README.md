# Executive Sales Dashboard Analysis

## Executive Summary

This project demonstrates how SQL can be used to solve real-world business problems by creating an Executive Sales Dashboard from a relational sales database. The analysis focuses on identifying high-performing customers, products, cities, and customer segments while calculating key business metrics that support executive decision-making.

## Business Problem

Executives need quick access to reliable sales metrics to monitor company performance, identify opportunities for growth, and make informed business decisions.

The objective of this project was to answer common executive-level questions using SQL while following professional query design practices.

## Database Schema

The project uses four related tables:

- Customers
- Orders
- Products
- Returns

Relationships are established through primary and foreign keys.

## Dashboard Reports

1. Top Customers by Revenue
2. Revenue by City
3. Revenue by Customer Segment
4. Top Products by Revenue
5. Customer Revenue Tier Classification
6. Highest Revenue Customer in Each City
7. City Revenue Share
